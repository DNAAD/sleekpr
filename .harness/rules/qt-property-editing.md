# Qt 属性编辑补充规则

适用于标签设计器属性、绑定、自动应用及工作台字段提示。基础分层、中文注释、审查工具限制和 Qt 原生链路继续遵守 [AGENTS.md](../../AGENTS.md)。

涉及后台预览、隐藏/关闭窗口、非法 JSON 或保存状态时，同时使用 [异步预览与草稿规则](async-preview-and-drafts.md)；模板来源与响应身份的区别见 [两类模板身份](../wiki/template-identity.md)。

## 绑定与事务

- 数据 key 与显示名称始终分开。不能从“名称（key）”等展示文字反向解析 key，不能用名称取代接口数据键。
- 改 key 只修改当前元素的精确引用。多键改名一次完成，防止交换键名或前缀相同的键被连续字符串替换串改。
- 元素与名称覆盖必须原子写回。无效键或名称冲突不得留下部分修改；不能顺便重命名其他元素、schema、样例数据或预设。
- 保留数组行内作用域和旧二维码空 `payload` 回退 `fieldKey` 的兼容行为，见 [绑定知识](../wiki/label-binding.md)。

## 自动应用与生命周期

- 刷新控件前比较实际文本；没有变化时不调用 `setText` 或 `setPlainText`，也不重建输入控件。保留焦点、光标、未完成输入及非法 JSON 草稿。
- key 输入途中暂时与另一引用同名时，不得立即去重并删除正在输入的行。保留编辑状态，完成输入后继续应用；回车或失焦后才确认合并。
- 使用已有防抖及渲染合并机制；无实际变化不制造撤销点，不因名称变更触发真实打印或改变正式绘制命令。
- 关闭窗口或销毁编辑器前，先断开可能引发自动应用的失焦信号、应用级焦点回调及相关回调链。不能让子控件析构信号访问已析构的文档成员。

## 问题提示与验收

- 定位依据结构化字段，不依据本地化错误文字。用户文案显示 `displayName`，机器定位和对外契约保留原 key。
- 校验详情不同时重复写入检查面板和底部状态栏；保存、提交及操作失败反馈不能随去重一起丢失。
- 预览定位高亮只能是界面叠加，不得进入正式图片或打印计划。
- 验证使用临时配置和模拟打印引擎，不得静默发送真实打印、覆盖操作员模板或关闭其客户端。
