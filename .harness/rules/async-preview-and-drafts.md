# 异步预览与草稿规则

适用于设计器、设置页和打印工作台的预览调度、窗口生命周期及保存状态。背景见 [设置保存与恢复](../wiki/settings-persistence.md) 和 [两类模板身份](../wiki/template-identity.md)。

## 异步结果的有效性

- GUI 线程读取控件并冻结输入；后台只接收普通数据、原生计划和 `QImage`，不持有 QWidget、QPixmap、借用的打印引擎或窗口成员引用，也不在工作线程读取 GUI `QPointer`。
- 复用应用作用域的 `PreviewExecutor`：全局最多两个工作任务，每个 `LatestPreviewQueue` 仅保留一个进行中和一个最新待处理任务。不为每次编辑新开线程或创建无界任务队列。
- 输入、模板、目标页或相关设备参数变化时同步失效旧结果；清空目标、隐藏或销毁窗口也要处理失效。工作台立即撤销旧打印可用状态，不等防抖计时器结束才禁印。
- 清空模板选择还须停止待规划计时器、清理待处理与已准备快照。结果发布和打印入口均检查当前有效选择，不能让空标识回退默认模板并打印旧结果。
- 只有当前代号且接收者仍存在的结果才能在 GUI 线程发布。未启动工作可取消并释放快照，已经开始的旧工作可完成后丢弃；“失效”不等于已强制终止工作线程。
- 执行器先于 QApplication 析构并收束后台任务；窗口队列销毁不等待计算。子控件销毁前断开可能触发自动应用的回调，不能让其访问已销毁成员。
- 隐藏窗口合并外部通知、显示后按需刷新；外部刷新不覆盖有效或非法草稿。纯显示名称、份数变化不应无条件触发全部版式规划。

## 未应用原文与保存基线

- 分别跟踪编辑器原文、有效模型和最后成功保存快照。非法模拟 JSON 不进入有效模型，但必须独立计入未保存草稿，并保留行列提示。
- 同一模板的属性刷新、其他属性保存成功，不得覆盖非法原文或清除其脏状态。待自动应用、待设置保存的计时器也属于未完成编辑，不能只看当前模型差异。
- 关闭先提交有效的待应用修改，再对剩余未保存/非法草稿确认；确认隐藏后，本次运行内再次打开需复用草稿窗口。显式重读或恢复经确认后才能放弃草稿，不承诺跨进程保留非法原文。
- 工厂建立的初始兜底文档不自动算用户修改；保存失败不推进成功基线。不得为消除未保存提示把非法原文塞进 `sampleData`，或把导出有效模型描述为导出了全部编辑器文本。

## 后台保存与退出

- 预览可以丢弃旧计算结果，保存不可以。已经执行的存储任务必须结算，窗口观察者销毁不能丢弃服务已接受的有效保存目标。
- 同会话合并未开始的累计意图，不能丢弃另一会话；禁止在 GUI 做完整模板序列化/差量比较或同步等磁盘。保留专用保存工作线程及原有仓库锁/备份规则。
- 原始观察基线、当前有效模型、非法原文、自身保存确认和仅运行时应用分开跟踪。确认自身路径不能把外部字段顺带升级为用户基线。
- 保存完成不整体替换新草稿；队列和 GUI 票据上下文都必须有界。待重读/恢复的窗口不能继续接受随后会被控制结果覆盖的新输入。
- 退出收束依赖事件和结构化状态，不递归 processEvents，不在 GUI 阻塞等待，不强杀线程、不超时静默丢弃。取消退出必须失效旧退出代次。
- 放弃未保存内容不能中止在途原子提交或回滚已保存数据；最终授权前保留可取消的待处理意图。手动表单“不保存”与放弃全部队列严格区分。
- 冻结/恢复操作要保留原有禁用状态，并区分“加载禁用”和“退出暂停”；不能因取消退出把尚在加载或原本校验禁用的控件错误启用，也不能使加载后的窗口永久禁用。
- 新命令行冒烟模式必须先建立明确隔离分流，再执行；不能用未知参数盲启可能忽略参数的旧客户端。新冒烟在生产设置、端口、托盘与真实引擎之前分流。

## 身份与验证

- 字段 key、显示名称、模板来源选择键、响应 `templateKey` 和文档 ID 各有用途；比较前确认身份类型相同，不从本地化展示文本或错误文案推断身份。
- GUI 回归等待可观察状态，不假定后台图片在 20/30ms 内完成。正式图像等待 `hasCurrentImage()`；错误等待结构化错误；诊断底图观察诊断状态及图片就绪，不把诊断页当正式可打印结果。
- 测试覆盖慢 A 被 B 替代、清空选择、关闭后完成、隐藏后显示、非法草稿与待保存计时器；保留正常打印/预览正向断言，避免保护条件误拦合法结果。慢工作池和日志命令见 [验证技能](../skills/verification/SKILL.md)。
