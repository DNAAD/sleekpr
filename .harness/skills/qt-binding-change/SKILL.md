# 修改 Qt 标签绑定

## 入口与范围

先读 [绑定知识](../../wiki/label-binding.md) 和 [属性编辑规则](../../rules/qt-property-editing.md)。仅修改当前需求相关的元素类型，不恢复延后的复杂表格功能，不改成浏览器排版。

## 执行流程

1. 沿 Presenter → 属性面板 → Command → 文档写回读取实际实现；涉及工作台时继续检查输入 schema、问题报告与共享打印服务。
2. 列覆盖矩阵：绑定字段、文本多个占位符、二维码表达式和旧单字段绑定、数组数据源及行内字段、无数据引用的固定内容和矩形。标清需要变化与必须保持的行为，不能只测试已接入的类型。
3. 先写并观察失败回归，再实现最小修改。GUI 等待采用可观察条件；读取异步回调结果前必须确认结果存在，不能在 `QTRY_*` 表达式内先解引用空列表。修改容器后不要继续使用可能失效的元素引用。
4. 面板只提供输入状态和语义信号；命令负责校验、精确替换与原子写回。复用名称解析和现有模板序列化，不复制一套字段映射或打印规则。
5. 先运行受影响的单项测试，再按 [验证技能](../verification/SKILL.md) 完成完整回归和原生截图检查。只报告实际验证结果；代码通过不等于正式包已更新。

## 必查场景

| 场景 | 验收结果 |
| --- | --- |
| 同名显示名称、重复引用、交换两个 key | 按真实 key 区分，普通文本及其他元素不被串改 |
| 名称改动、清空覆盖、切换模板 | 取值与规则不变，只更新当前模板名称，不丢草稿 |
| 数组行模板新增完整占位符并停顿超过防抖时间 | 引用列表更新，文本编辑光标和焦点不变 |
| `${a}/${b}` 的第二个键输入到 `a` 后停顿，再继续 `Long` | 编辑行不消失；确认前不丢失原引用，确认同键后才合并 |
| 旧二维码清空内容后改绑定 key | 真实绑定被更新，不能仍读取旧 key 且不报错 |
| 无效键、冲突名称、已删除的占位符 | 不留下半次修改或无意创建名称覆盖 |
| 防抖期间保存、撤销重做、带焦点关闭窗口 | 保存包含有效待应用修改，历史合理，关闭无回调越界 |

增加测试时复用 `tests/tst_label_designer.cpp` 中相关回归和临时配置，不向真实设备发送任务。名称或高亮变化不能改变正式绘制命令。
