# 标签画布编辑

本阶段只增强普通标签元素，不恢复复杂表格设计器；正式预览和打印仍使用 Qt 原生链路。

## 选择与布局

- 单击选择对象，Ctrl 或 Shift 单击增减选区；空白区域拖动框选，单击空白清空选择。
- 在画布按 Ctrl+A 选择所有可编辑对象；锁定、隐藏对象及其图层不参与画布编辑。
- 拖动选区整体移动，八个控制点调整布局区域尺寸。多选缩放按原选区比例变换，单个元素最小边为 0.5 mm。
- 缩放布局区域不会直接改变字号或数组网格行高；文本的字号自适应仍由原有自动适配设置控制。
- 智能吸附默认开启，吸附纸张和可见对象的边缘、中心，容差为 5 个逻辑像素。可在对象菜单关闭。
- 对象菜单和画布右键菜单提供对齐、均匀分布。单选对齐纸张，多选对齐选区，等距分布至少需要三个可编辑对象。
- 多选时属性面板显示对象数量，不把某一个对象的属性误当作全部对象的属性。

## 编辑命令

- Ctrl+C / Ctrl+V：复制和粘贴完整对象属性与字段绑定；粘贴到当前可写图层，默认偏移 2 mm，整体约束在纸张内。
- Ctrl+D：创建选区副本；Alt 拖动：拖出副本。每次复制生成新 id，不覆盖原对象。
- Delete：删除选区；方向键微调 0.1 mm，Shift+方向键移动 1 mm。
- Ctrl+Z：撤销；Ctrl+Y 或画布中的 Ctrl+Shift+Z：重做。
- Esc：取消当前拖动并恢复文档；未拖动时清空选区。

## 字段绑定

- 选中绑定字段元素后，右侧分别编辑“绑定 key”和“显示名称（displayName）”。当前 key 显示为 `productName`，下拉选项仍显示“商品名称（productName）”以便识别；模板和接口始终按原始 `fieldKey` 取值。
- 名称默认采用当前模板 `fieldSchema` 的 `displayName`，内置字段提供中文兜底；用户修改的名称以当前模板的 `fieldDisplayNames` 对象保存，优先于这些默认名称，不新增字段声明，也不更改类型、必填、默认值及模拟值。
- 当前模板内相同 key 共用显示名称，工作台表单和输入检查使用同一名称；其他模板不受影响。名称支持自动应用、撤销/重做和模板保存加载、导入导出。清空覆盖名称后恢复默认名称。
- 修改绑定 key 只改变当前元素的绑定，不批量重命名其他元素、样例数据或预设，也不会把旧 key 的名称带给新 key。显示名称不自动成为标签打印内容。
- 没有名称的旧字段仍显示并保留原 key；右侧自定义按钮可输入未列出的 key，取消输入不修改模板。字段名称相同也按不同 key 分别绑定。
- 固定文本和二维码的内容编辑器下方增加“数据绑定”，按每个独立占位符分别填写 `key`、`displayName`；同一 key 的重复引用只列一次。纯固定文本、固定二维码内容和矩形不显示数据绑定。
- 数组网格的数据源及单元格模板中的行内字段也分别显示 `key`、`displayName`，行内变量不会因此变成顶层输入字段。空单元格模板按现有渲染规则显示 `value` 引用。
- 改 key 只精确更新当前元素内的对应占位符或数组路径，不修改普通文字，不批量重命名其他元素、接口数据或预设。修改多个 key 时同时替换，交换键名不会串改。
- 所有名称继续存入当前模板的 `fieldDisplayNames`；相同 key 共享名称。修改 key 不携带原 key 的名称；清空显示名称恢复默认。无效 key 和相同 key 的名称冲突会阻止整次属性修改。
- key 输入中途暂时与另一行相同时，自动应用会暂缓合并并保留编辑行；继续输入可正常完成改名，回车或失焦后才确认同 key 合并。绑定列表刷新不会重置文本和数组模板编辑器的光标。
- 旧二维码的单字段 `fieldKey` 绑定保持兼容，修改名称或坐标不转换为另一种存储形式。预览和打印仍按原 key 读取真实数据，显示名称不参与排版或编码。

## 性能与边界

选区、控制点、框选框和吸附线只在画布覆盖绘制，不进入 PNG 预览和打印计划。连续拖动只保留一个待执行的预览帧，属性面板和设置通知在操作完成后更新，一次拖动只形成一个撤销点。

剪贴板使用专用 MIME 和现有模板 JSON 格式，限制为 2 MB、500 个元素；数组网格单轴不超过 20 格，单次粘贴总格数不超过 10000，非法尺寸和不受支持的结构会被拒绝。

## 本地验收

本次生成的是 `build/sleekpr.exe`。退出仍在运行的旧客户端后，通过 `quick-start.cmd -Mode Debug` 启动。默认 Release 启动路径不会因 Debug 构建自动更新，正式打包需单独执行发布构建。

自动化覆盖包括核心几何、设备校准坐标、画布高 DPI 覆盖层、选区与菜单、复制粘贴、撤销重做和拖动取消。真实打印机的操作手感与出纸结果仍需设备冒烟验收。
